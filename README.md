# Joulesmith

An all-in-one tech mod for Minecraft 1.21.1 on NeoForge: power, item and fluid transport, processing, automation, farming, storage, and powered armor, tools and weapons, from a coal generator to a fusion core.

**Status:** early development.

## Building

```
./gradlew build
```

The built jar is in `build/libs/`. Run a test client with `./gradlew runClient`.
