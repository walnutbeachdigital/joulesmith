# Joulesmith

**From a coal generator to steam turbines, quarries and a powered Exo-Suit: one tech mod where everything plugs together.**

Joulesmith is an all-in-one tech mod for Minecraft 1.21.1 on NeoForge. Power, pipes, machines, farms, storage and gear share one tier ladder (Basic, Reinforced, Advanced), one machine screen and one set of rules, so you always know what to build next. The look follows classic Thermal-style pixel art: steel casings, bright colour-coded fronts and trims that show each block's tier.

## Features

**Power.** Burn fuel in a Combustion Generator, grow it for the Biofuel Generator, tap lava with the Geothermal Generator, or go renewable with Solar Panels and Wind Turbines. Later, a Boiler and Steam Turbine power a whole base. Store it in batteries and move it with cables in three tiers.

**Transport.** Item Ducts, Fluid Pipes and Energy Cables connect on their own; set each side to push, pull or off with the Wrench. Filter Cards sort by item, tag or mod. Pumps, tanks and Conveyor Belts round it out, and Upgrade Kits move a working line up a tier without tearing it down.

**Processing.** Twelve machines turn one raw ore into two, three, then four ingots as you climb the tiers: crushing, washing, then dissolving ore in acid and growing crystals from the slurry.

**Automation.** Block Placers and Breakers, an Autocrafter, a Quarry, a Mob Fighter, Sensors and a Logic Controller that can say "if the battery is below 20%, start the generators."

**Farming.** Planters, Harvesters, Tree Farms, Sprinklers, Hydroponic Beds, an Animal Rancher, a Mob Grinder that stores XP as a fluid, and an Auto Enchanter to spend it.

**Gear.** Copper, bronze and steel tools and armor, then FE-powered gear: a Power Drill, Chainsaw, Energy Sword and the four-piece Exo-Suit, all charged on a Charging Pad and customised with modules like Fortune, Jetpack, Night Vision and Chain Lightning.

## Compatibility

Joulesmith uses NeoForge's standard FE, item and fluid capabilities, so it works alongside other tech mods. Optional support for JEI, Jade, The One Probe, CC: Tweaked and Curios. Balance settings live in `config/joulesmith-common.toml`; recipes and ore generation can be changed with data packs.

## Requirements

Minecraft 1.21.1 and NeoForge 21.1. Install on both client and server.
